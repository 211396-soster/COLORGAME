# ColorTintas — projeto Godot

Repositório central do projeto de jogo **ColorTintas**, desenvolvido com Godot 4.

## Como agentes de IA devem começar

1. Leia `AGENTS.md` antes de alterar qualquer arquivo.
2. Leia `docs/MEMORIA_MESTRA.md` para entender o contexto compartilhado.
3. Confira `docs/ESTADO_ATUAL.md`, `docs/ARQUITETURA.md` e `docs/ROADMAP.md`.
4. Faça alterações em uma branch própria; não sobrescreva trabalho de outro agente.
5. Atualize a documentação e o changelog quando uma mudança alterar o projeto.
6. Abra um Pull Request com resumo, arquivos alterados e testes executados.
