# Roadmap inicial

> Prioridades propostas para validação pelo responsável. Não representam funcionalidades já implementadas.

## Fase 0 — Integridade e colaboração
- [ ] Confirmar importação limpa no Godot 4.4+.
- [ ] Executar a cena inicial e registrar erros.
- [ ] Testar separadamente os modos de entrega, loja/cozinha e zumbis.
- [ ] Confirmar exportação Android e assinatura segura.
- [ ] Definir branches e proteção de `main`.

## Fase 1 — Qualidade de jogo
- [ ] Criar lista reproduzível de bugs.
- [ ] Medir desempenho em dispositivo Android de referência.
- [ ] Validar controles touch, resolução, orientação e interface.
- [ ] Verificar carregamento de recursos e colisões no mapa.

## Fase 2 — Fluxo multiagente
- [ ] Definir tarefas independentes e responsáveis/agentes.
- [ ] Exigir branch e pull request por tarefa.
- [ ] Ativar verificação automática de importação no CI.
- [ ] Revisar diff, testes e documentação antes do merge.

## Fase 3 — Publicação
- [ ] Definir plataformas e dispositivos suportados.
- [ ] Definir versionamento e notas de versão.
- [ ] Manter keystore/credenciais fora do Git e usar segredos de CI.
- [ ] Validar licenças e atribuições de assets e dados do mapa.
